1. Executive Summary

The **AI Forensics Time Machine** is an advanced, production-grade cybersecurity platform designed to simplify the complex task of digital forensic log analysis. By leveraging modern AI models (Google Gemini) and real-time visualization techniques, the system enables security analysts to upload raw system logs, detect threats automatically, and reconstruct attack sequences through interactive timelines and graphs. This project bridges the gap between raw data and actionable intelligence, providing automated remediation recommendations and exportable forensic reports.

2. Introduction

In the modern digital landscape, large-scale systems generate millions of log entries daily. Manually auditing these logs to identify malicious behavior is nearly impossible for human analysts. Traditional Security Information and Event Management (SIEM) tools often produce high noise and require significant manual configuration.

The AI Forensics Time Machine addresses these challenges by introducing an "AI-First" approach to forensics. It utilizes a modular architecture to parse multi-format logs, identify suspicious patterns using rule-based and behavioral heuristics, and then uses Large Language Models (LLMs) to generate human-readable narratives of security incidents.

3. Project Objectives

  • Automated Ingestion: To support various log formats (Linux, Windows, Network) with automated parsing.
  • Threat Detection: To implement a comprehensive rule engine capable of identifying 20+ types of cyberattacks including brute-force, privilege escalation, and reconnaissance.
  • Visualization: To provide interactive Cytoscape-based attack graphs and Chart.js timelines for spatial and temporal analysis.
  • Forensic Replay: To enable step-by-step chronological playback of security incidents for deep-dive investigation.
  • AI Analysis: To integrate Google Gemini AI for generating executive summaries and remediation steps.

5. System Architecture

The system follows a modern client-server architecture. The backend is responsible for data ingestion, processing, and AI orchestration, while the frontend handles high-performance data visualization.

5.1 Data Flow

  1. Ingestion: Users upload log files (`.log`, `.txt`) or select live sources via the dashboard.
  2. Parsing: The Parser Service uses regex-based patterns to normalize logs into a structured Event format.
  3. Detection: The Detection Engine scans events for threat signatures (e.g., repeated login failures).
  4. Reconstruction: The Analyzer Service groups related events into Attack Chains.
  5. AI Enrichment: The AI Service processes incident data to generate summaries.
  6. Delivery: JSON data is served to the React frontend via REST endpoints and WebSockets.

6. Key Features

  • Real-Time Monitor: Live streaming of system logs using WebSockets for immediate detection of threats.
  • Attack Reconstruction Graph: Visual mapping of attackers (IPs) to targets (Users/Processes).
  • Event Timeline: A temporal view of system activity with severity-based filtering.
  • Forensic Replay UI: Controls to speed up or slow down the playback of an incident.
  • Auto-Generated PDF Reports: Professional forensic documentation ready for board-level review.

7. Detection Methodology

The system employs a hybrid detection model:

7.1 Rule-Based Engine

A signature-based engine identifies known patterns of abuse. Key rules include:

  • Brute Force: Detection of 5+ failed login attempts within 60 seconds.
  • Privilege Escalation: Tracking unauthorized `sudo` executions.
  • Suspicious Recon: Commands like `whoami`, `ifconfig`, and `nmap` execution patterns.

7.2 AI Behavioral Analysis

When a Gemini API key is provided, the system sends anonymized attack sequences to Google's AI models. The AI provides:

  • Narrative Generation: Translating raw logs into "The attacker gained access via X and attempted to Y."
  • Remediation: Recommending security patches or firewall rules.

8. Implementation Details

The project was implemented over several modules:

  • Loghub Integration: Supports the Loghub benchmark dataset for testing.
  • Cyber-Security UI: Designed with a "Neo-Cyberpunk" aesthetic using CSS variables for consistent theming.
  • Responsive Design: Fully functional across desktop and tablet browsers.

9. Conclusion

The AI Forensics Time Machine demonstrates the power of combining traditional digital forensics with generative AI. It significantly reduces the Mean Time to Detect (MTTD) and Mean Time to Respond (MTTR) by providing automated insights. Future enhancements could include full EDR (Endpoint Detection and Response) capabilities and integration with SIEM platforms like Splunk or Elastic.
